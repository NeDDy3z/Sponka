# Support

## Need help?

Start with the [wiki](https://github.com/NeDDy3z/Sponka/wiki). It has short tutorials for everything Sponka adds on top of xnotes: cloud sync, handwriting to text and math, importing and reading files, shapes and tables, selecting and erasing, and the settings. The full list of additions is in [ADDITIONS.md](ADDITIONS.md).

## Open an issue

| | |
|---|---|
| [Report a bug](https://github.com/NeDDy3z/Sponka/issues/new?labels=bug&assignees=NeDDy3z&body=Sponka%20version:%0ADevice%20and%20Android%20version:%0AStylus:%0A%0AWhat%20happened:%0A%0AWhat%20you%20expected:%0A%0ASteps%20to%20reproduce:%0A1.%20) | Something is broken or behaves wrong |
| [Request a feature](https://github.com/NeDDy3z/Sponka/issues/new?labels=enhancement&assignees=NeDDy3z&body=What%20you%20want%20to%20do:%0A%0AWhy%20it%20would%20help:%0A) | A new feature or a change to an existing one |
| [Report a translation](https://github.com/NeDDy3z/Sponka/issues/new?title=Incorrect%20Translation&labels=translation&assignees=NeDDy3z&body=Language:%0ALocation:%0AIncorrect:%0AFix:) | A wrong or missing translation |
| [Ask a question](https://github.com/NeDDy3z/Sponka/issues/new?labels=question&assignees=NeDDy3z) | Anything the wiki doesn't answer |

Please keep one bug or idea per issue. Smaller issues are easier to track, so nothing gets missed.

For bugs, screenshots/screen recordings help a lot. For sync problems, add the log from the Sync log.

## Bugs in the original xnotes

If a does affect the original [xnotes](https://github.com/shardulvs/xnotes-android) too, you can post it here too, I'll fix the bug and then propagate the fix to upstream.
